# Style guide: picking a style

| Topic | Style |
|---|---|
| Space, planets, physics, time, the universe | **cosmos** |
| Human body, biology, chemistry, animals, medicine, tech | **lab** |
| **Default for every video (the owner's chosen look)** | **flat** |
| History, ancient civilisations, archaeology, old inventions, wars | **archive** |
| Survival, disasters, "what if" scenarios, danger, extreme limits | **alert** |

When a topic fits two styles, pick by **emotion**:
- wonder → cosmos
- "huh, that's weird" → lab
- intrigue about the past → archive
- tension or danger → alert

Avoid using the same style three days in a row (check `_published.md`) unless the topic clearly needs it.

Read the chosen style's `STYLE.md` in full before writing shots.
